# CSV 三方合并工具

```bash
docker compose up --build
```

然后在浏览器打开 http://localhost:3000

上传基准 / 本地 / 远端三份 CSV 完成三方合并后，页面会展示**合并结果来源账本**：
按最终 CSV 行序逐格标注最终值的取值来源（基准 / 本地 / 远端 / 两侧相同 / 人工填写）
与原文件行号，删除键单独列出原因，并可下载 JSON 账本存档复核。

冲突全部裁决后还可以做**父子层级核验**：从表头中选择父键列（不能是唯一键列），
服务端按最终保留行以最终唯一键建立索引——空父键视为根，其余父键按原字符串精确匹配，
指向不存在或已删除键的行报缺失父项，指向自身或相互成环的环上成员报循环；
问题按最终 CSV 行序列出问题键、父键、类型与输出行号，可下载 JSON 结果，
核验只提示问题，不改变导出的 CSV。

层级有效（无缺失父项、无循环）时，还能生成**父子数据导入顺序**：按父先子后排序——
每步从当前可输出的行里选原合并 CSV 行序最早者；页面展示排序后的键序，
可下载沿用基准表头与原单元格值的顺序 CSV（`import-order.csv`）。
存在缺失父项或循环时列出问题键与类型并阻止顺序导出，原有合并 CSV 导出仍可用；
修改裁决或父键列后自动重新计算。

裁决完全部冲突后，还可以把这些冲突行下载为**跨轮裁决方案**（JSON，记录唯一键列、表头、
三方存在状态与各列原值、冲突类型和裁决，不含 roundId 与原文件行号）；重新上传并比对后
导入方案，服务端按唯一键逐行核对——键列、表头、三方原值与冲突类型完全相同的行才整行套用，
行序和原文件行号变化不影响；本轮已手动裁决的行整行跳过，格式错误不改动任何裁决，
页面列出已套用与跳过的行及原因。CSV 导出、来源账本与层级核验都读取套用后的本轮裁决。

冲突全部裁决后，第 7 区提供**疑似唯一键变更核对**：服务端从本轮基准与最终结果提取
消失键（基准有、最终结果没有）和新增键（最终结果有、基准没有），两组各限 12 个、
超限明确提示。选择至少一个非键比较列并设置 0 至比较列数的整数差异上限后，
逐格按原字符串比较、以不同格数为代价，超限的行对不能配对；服务端求允许交叉的
一对一配对（先让配对数最多、再让总代价最小），并对每个消失键列出所有最优方案中
可能对应的新键与是否可能未配对——只有所有最优方案都配向同一新键时才标为稳定候选，
候选只是核对线索，不能认定为真实改名。页面展示最优配对数、总代价与候选代价，
可下载 JSON；核对不改变任何数据与裁决，改动裁决或核对参数后自动重算。

冲突全部裁决后，第 8 区提供**最小决定列发现**：选择一个非键目标列和 1～10 个互异
候选列（不能含目标列或唯一键列），服务端从本轮模型与裁决取得最终保留行
（最多 300 行，超限提示，无行时提示无数据），逐格按原字符串比较（空串也是值）：
任意两行在组合各列相同就必有相同目标值时该组合成立；枚举**所有**成立且任何真子集
均不成立的组合（不只列数最少者，目标恒定时只返回空组合），每个非空组合逐列移除并
附一对证明失效的行键与目标值，无组合时给出全候选列相同而目标不同的字典序最早反例。
页面按列数、基准表头列序排列组合，可下载 JSON；结论注明**仅适用于当前数据**，
裁决或选列变化后自动重算，未决冲突、轮次失效时清除结果，不改变 CSV 导出。

冲突全部裁决后，第 9 区提供**合并金额尾差分摊**：选择互异的分组列与金额列
（分组列按原字符串分组，空串也成组），金额以元计、只接受非负无指数最多四位
小数的十进制字符串，空值或非法值逐行指出最终 CSV 行号并拒绝整次计算；
各组精确求和后四舍五入到分，每行先向下取整到分，再将差额按不足一分的余数
降序、同余数按最终行序逐分分配。页面展示每组总额与逐行分摊额，可下载按原行序
追加「分摊金额」列的 CSV（原表头已有同名列明确报错，无行时只输出新表头）；
服务端只从本轮模型与裁决取数，裁决或选列变化后自动重算，原合并 CSV 不变。

应用代码与详细文档见 [`csv-3way-merge/`](./csv-3way-merge) 目录。
